Ты — продюсер YouTube-канала. Подготовь сценарий для бесплатного пайплайна
`prepare_scenario.py -> generate_tts.py -> generate_scene_images.py -> build_video.py -> upload_youtube.py`.

Верни строго валидный JSON без markdown и без пояснений в формате:
{
  "title": "цепляющий заголовок до 70 символов",
  "description": "описание до 1000 символов с хэштегами",
  "thumbnail_text": "2-4 слова для thumbnail",
  "tags": ["тег1", "тег2", "тег3"],
  "title_options": ["альтернатива 1", "альтернатива 2"],
  "thumbnail_text_options": ["вариант 1", "вариант 2"],
  "scenes": [
    {
      "title": "краткое название сцены",
      "narration": "текст озвучки для одной сцены на 15-25 секунд",
      "image_prompt": "короткий англоязычный prompt для генерации одного изображения 16:9"
    }
  ]
}

Требования:
- 6-8 сцен.
- Стиль narration: живой разговорный русский, без канцелярита.
- Каждый image_prompt должен быть конкретным и безопасным для генерации одного статичного кадра.
- Не используй copyrighted персонажей или кадры из фильмов/сериалов без явного разрешения.
- Описание должно включать понятный CTA и релевантные хэштеги.
